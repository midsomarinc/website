Midsomar

Midsomar is an SDK that puts a full coding agent on your machine. Install it, start it, and you have a capable agent reading, editing, and running your codebase locally — no accounts, no cloud sandbox, nothing leaving your filesystem unless you tell it to.

Install

$ npm install midsomar

Run it

$ npx midsomar web

That's it. This starts a local server and opens the agent in your browser, pointed at the project in your current directory. No further setup, no config file required to get moving.

Midsomar runs entirely on your machine. The agent reads your working directory directly and executes commands in a local shell, so it works offline-friendly and keeps your code where it already lives.

Providers

Midsomar isn't tied to one model. Open the desktop app's Providers screen and connect Anthropic, OpenAI, Google, GitHub Copilot, or OpenRouter — or point it at any OpenAI-compatible endpoint to bring your own model.
